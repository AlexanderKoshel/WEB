## Лабораторная №1: React

Ветка `lab1`, проект находится в `Task_1`. Собственный поиск:
вариант 10 — «Ресторан. Меню».

### Установка и запуск

Нужны Node.js и npm. Все команды ниже выполняются из папки `Task_1`:

```powershell
cd Task_1
npm ci
npm run build
npm start
```

Открыть http://localhost:3030/. Страницы:

- `/getting-started.html` — имя из модели, редактируемый девиз и таймер.
- `/p2.html` — поиск областей Беларуси без учёта регистра.
- `/MySearch.html` — поиск блюд ресторана без учёта регистра.

Во втором терминале из `Task_1` можно запустить `npm run build:w`:
сборка будет обновляться после сохранения исходников. Страницу обновлять вручную.
Остановка сервера или сборщика: `Ctrl+C`.

### Проверка

1. `npm run build` завершается без ошибок и создаёт три bundle-файла в `compiled`.
2. Example показывает имя из `modelData/example.js`. При вводе девиза текст
   меняется сразу; счётчик увеличивается каждые две секунды.
3. Regions: пустой запрос показывает все семь элементов; `нс` и `НС` дают
   `Гродненская`, `Минск`, `Минская` в алфавитном порядке.
4. Меню: запрос `паста` и `ПАСТА` показывает два блюда; `салат` — два салата.
5. В обоих поисках несуществующий запрос показывает «Совпадений не найдено»;
   очистка ввода возвращает весь отсортированный список.
6. В консоли браузера нет ошибок; результаты отрисовываются Material UI List/ListItem.

Модели остаются отдельными файлами, как в исходном шаблоне. Все React-компоненты
функциональные; состояние ввода хранится в `useState`, таймер Example управляется
через `useEffect` с очисткой.

`node_modules`, результаты сборки и условия лабораторных не отслеживаются Git.
