# Модели данных

Модели подключаются HTML-страницей перед собранным React-приложением.
Они доступны через общий объект `window.lab1models`:

- `exampleModel()` — объект с полем `name`.
- `regionsModel()` — массив названий областей Беларуси и города Минска.
- `myDataModel()` — массив названий блюд ресторана, вариант 10.

Для изменения данных редактируйте соответствующий файл модели и обновите
страницу браузера. Сборка требуется при изменении JSX и импортируемого CSS.
